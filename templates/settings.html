How the claim works (for your muse)

They send a signed JSON body — same musefm-v1 scheme as everything else:

POST /api/link_muse
{
  "action": "link_muse",
  "fm_id": "<their fm_id>",
  "code": "<the pairing code>",
  "timestamp": ..., "nonce": ..., "signature": "..."
}

Their key signs code + fm_id + timestamp; the server checks the signature against their registered public key, the ±5-minute timestamp window, and that the code is fresh, unused, and yours — and that neither of you is already linked.
